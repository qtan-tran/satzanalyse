satzanalyse

Ancient Greek sentence analysis – paste Greek text, get an analysis worksheet as HTML + LaTeX

Tool Guide Corpus Toolkit ↗ VN edition ↗ GitHub ↗

1. Workflow

  • Paste your Greek text into the box on the Tool page (keep all accents and breathings).
  • Build the frame: the tool splits the text into sentences (at . · ; ! and line breaks), tokenises it into word blocks, and generates two files: a self-contained HTML worksheet and a .tex (LaTeX) source.
  • Fill it in: the blank cells are the point of the method – the tool never fabricates an analysis. You assign the sentence function to each word block (following the colours in the legend), fill in the morphological forms, the verb table, the glosses, the sense-group table and the translations.
  • Export a PDF using one of the two methods in section 3 below.

2. Structure of the analysis frame

PART 1 – Sentence-by-sentence analysis

  • One frame per sentence: a three-layer word-block diagram (function – word – form). The function cell is blank … for you to assign; the form cell carries a morphology hint: closed-class forms (articles, familiar pronouns, εἰμί) are certain; particles/conjunctions/prepositions/adverbs read "invariable"; ending guesses end with "?" – verify them; "(form?)" = the tool could not guess, fill it in yourself.
  • "Translation by sense groups" table: the sentence is pre-split into chunks of about four words so you can see how the sense groups connect before translating the whole sentence. The default split is mechanical – regroup it by meaning; the two meaning columns are yours to fill in.
  • Verb table with 8 columns (form | lemma | person | number | tense | mood | voice | subject): enter every finite verb form of the sentence; if the subject is not written out, note "inside the verb ending (person … number …)".
  • Seven steps: each step is pre-filled with its method prompt (find the verbs → subjects → word blocks → government → AcI → negation → translate). Work through them directly inside the frame.
  • Translation: literal version (wörtlich) → natural version (natürlich). After the last sentence comes the "Full translation" box.

PART 2 – Vocabulary and patterns

  • Vocabulary table: every word in order of appearance, without duplicates. The lemma/POS/gloss columns are pre-filled when the dictionary finds the word (marked ★); blank cells = not found (an inflected form outside the dictionary, a proper name, or a form that stays ambiguous between several words) – look it up and fill it in. The "Suggested form" column guesses the morphology ("?" = verify).
  • Pattern boxes: three empty boxes (Example → Rule → Recognition tip) to extract a pattern you can transfer to other examples.
  • Endings table: pre-filled with the endings recognised in the text (ending, what it identifies, examples). Every row is a suggestion to verify; closed-class forms and indeclinable words have no ending, so they never appear here. Space remains for you to add more.

3. Exporting a PDF yourself

satzanalyse does not render PDFs itself. The two methods below give the best results:

Method A – print the HTML file from the browser (fastest)

  • Open the downloaded satzanalyse.html in a browser (Chrome/Edge/Firefox).
  • Press Ctrl+P (Windows/Linux) or Cmd+P (macOS), choose Save as PDF.
  • The print CSS is already set up: one sentence per page, frames never split across pages.

Method B – compile the .tex file on Overleaf (highest quality)

  • Open overleaf.com → New Project → Blank Project, name it as you like.
  • Upload satzanalyse.tex to the project (Upload button) or use "Copy .tex content" on the Tool page and paste it into main.tex.
  • Menu Settings → Compiler: choose XeLaTeX (required – the .tex uses fontspec with FreeSerif/DejaVu, both available in Overleaf's TeX Live).
  • Press Recompile twice so the longtable stabilises → download the PDF.
  • Local compilation: run xelatex satzanalyse.tex twice (needs TeX Live/XeLaTeX plus the FreeSerif and DejaVu fonts).
In the .tex file the translation line keeps the markers wörtlich (literal version) and natürlich (natural version) of the original Satzanalyse format.

4. Limits & friendly errors

  • 1,500 characters (≈ 15–20 sentences) per run – the counter sits directly under the text box; over the limit the tool shows an error and suggests splitting the text.
  • The tool only accepts Greek characters: pasting purely Latin text gives a warning.
  • Your input is normalised to Unicode NFC, so text with decomposed accents (or copied from a source with inconsistent encoding) still matches the dictionary and renders cleanly.
  • Integrated dictionary (Part 2): when a word is not found directly, the tool tries to guess it back to the dictionary by stripping a case/personal ending and the ἐ- augment; when exactly one lemma matches, it pre-fills the gloss with the label "(ending stripped)" (the meaning is right, but the base form is a suggestion – verify); when nothing or several lemmas match, it does not guess – the cell stays blank.
  • Morphology hints (Part 2): closed-class forms are recognised with certainty; every ending-based guess carries a "?" so you verify it; indeclinable words read "invariable".

5. Feature roadmap

  • Part 2 – dictionary + morphology: the client-side core dictionary of ~6,200 classical Greek words (built from the Perseus Vocabulary Tool, the DCC Greek core list and Middle Liddell; see docs/COPYRIGHT.md) with explicit stems and part-of-speech classes; morphology hint tables covering nouns (all three declensions), verbs (thematic, contract, -μι), participles and the perfect.
  • Part 3 – sample corpus: fully analysed sentences from John's Gospel and Xenophon (easy prose) as worked examples: see corpus.html.
